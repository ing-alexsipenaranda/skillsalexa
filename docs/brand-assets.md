# Recursos gráficos para Alexa

La fuente oficial es `LifeOs/app/assets/brand/evoll-app-icon.svg` (1024×1024),
con fondo azul oscuro, bloque verde azulado, letra E blanca y punto menta.

Para la ficha de Alexa se deben exportar desde esa fuente, sin redibujar:

- Icono pequeño: PNG RGB, 108×108.
- Icono grande: PNG RGB, 512×512.

No añadir texto pequeño, transparencia, bordes nuevos ni elementos propios de
Amazon. Verificar legibilidad del punto menta y la E en el icono de 108 px.
