# Evoll for Alexa Privacy Policy

Last updated: November 1, 2026.

Evoll for Alexa lets a linked user access information from their Evoll account
by voice. The skill uses the linked account token and the user's permissions;
it does not use an administrative key to access personal data.

## Data processed

The skill processes the voice request received from Alexa, the access token,
and the Evoll information required to answer. Depending on the selected
permissions, it may access tasks, calendar, finances, goals, debts, and notes.
Tasks and reminders are saved only after explicit confirmation.

## Use and retention

Requests are used only to produce the requested response. The account-linking
service stores encrypted refresh tokens to maintain the connection for up to 90
days. Metrics contain status and duration without request text, responses,
tokens, or user identity.

## Controls

Users may restrict modules, enable private mode, disable voice actions, and
unlink the skill in Alexa. They may also revoke the connection from Evoll.
Responses can be heard by people near the device; private mode limits sensitive
information and visual cards.

## Providers

Authentication and data are managed with Supabase. Amazon Alexa transmits skill
requests. The agent configured in Evoll processes requests according to the
user's preferences.
