# Política de privacidad de Evoll para Alexa

Última actualización: 1 de noviembre de 2026.

Evoll para Alexa permite que una persona vinculada consulte información de su
cuenta Evoll mediante voz. La skill usa el token de la cuenta vinculada y los
permisos del usuario; no utiliza una clave administrativa para acceder a datos.

## Datos tratados

La skill procesa la consulta de voz recibida de Alexa, el token de acceso y la
información de Evoll necesaria para responder. Según los permisos elegidos,
puede consultar tareas, calendario, finanzas, metas, deudas y notas. Las tareas
y recordatorios solo se guardan después de una confirmación explícita.

## Uso y conservación

Las consultas se usan únicamente para generar la respuesta solicitada. El
servicio de vinculación conserva tokens de renovación cifrados para mantener la
conexión, con una vigencia máxima de 90 días. Las métricas contienen estado y
duración, sin texto de consultas, respuestas, tokens ni identidad del usuario.

## Controles

El usuario puede restringir módulos, activar el modo privado, deshabilitar
acciones por voz y desvincular la skill desde Alexa. También puede revocar la
conexión desde Evoll. Las respuestas pueden ser escuchadas por personas cercanas
al dispositivo; el modo privado limita información sensible y tarjetas visuales.

## Proveedores

La autenticación y los datos se gestionan con Supabase. Amazon Alexa transmite
las solicitudes de la skill. El agente configurado en Evoll procesa las
consultas conforme a las preferencias del usuario.
